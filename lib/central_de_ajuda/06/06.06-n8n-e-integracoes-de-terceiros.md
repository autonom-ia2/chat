## O que é

**n8n (Conexões do CRM)** é um guia de duas etapas para automatizar o funil
por fora: gerar um token de acesso e criar um webhook. Junto dela, três
cartões pedem conta em outro serviço — **Dialogflow**, **Tradutor do Google**
e **Dyte** — e um cartão antigo, **OpenAI**, que só aparece em contas que já
tinham essa configuração.

## Por que importa

O cartão n8n só existe se o recurso de CRM estiver liberado na conta e o CRM
Kanban estiver ligado. Sem essas duas condições, não adianta procurar.

O cartão **OpenAI**, quando aparece, engana: ele não alimenta o CRM, os
agentes de IA nem o Copiloto — isso é feito pelo **CRM Kanban IA** (veja
[06.02]). Ver os dois cadastrados é sinal de duas chaves, e possivelmente
duas faturas na OpenAI.

## Como faz

**Configurações → Integrações → n8n (Conexões do CRM)**

1. Clique em **Criar token de API do CRM**. O token deixa o n8n criar e mover
   cards; ele só é mostrado uma vez, no momento em que é gerado — anote-o ali.
2. Clique em **Criar webhook para eventos do CRM** para abrir o formulário de
   webhook, já com os seis eventos de card disponíveis para marcar.

Token e webhook são metades independentes: ter só um deixa a integração pela
metade.

**Dialogflow, Tradutor do Google e Dyte**

1. Abra o cartão do serviço que você usa e clique em **Configurar**.
2. Preencha os campos: Dialogflow quer Project ID e o JSON de credenciais,
   por caixa de entrada; Tradutor do Google quer Project ID e JSON; Dyte quer
   Account ID, App ID e API Token.

Esses três cartões aparecem para qualquer conta, sem portão na plataforma —
o bloqueio é você ter (ou não) conta e credenciais no serviço externo.

## O que dá errado

- **"O cartão n8n não aparece na minha conta."** Ele exige o recurso de CRM
  liberado e o CRM Kanban ligado ao mesmo tempo.
- **"Gerei o token e fechei a tela sem copiar."** Não tem como ver de novo:
  gere outro token e revogue o antigo.
- **"Configurei o token e nada muda no card."** O token sozinho não é uma
  conexão automática: crie também o webhook com os eventos.
- **"Cadastrei o webhook com o endereço do meu n8n e os eventos nunca
  chegam."** O cadastro não checa se o endereço é alcançável. Um n8n numa
  rede interna é bloqueado só na hora de entregar o evento, em silêncio.
  Exponha o n8n num endereço público antes de assinar.
- **"Só um administrador consegue gerar token do CRM?"** Administrador, ou
  função personalizada com a chave `crm_admin`.
- **"Apareceu um cartão OpenAI que eu nunca configurei."** Ele só existe
  nessa conta porque já havia uma configuração antiga guardada ali, ligada à
  sugestão de etiquetas — um recurso diferente do CRM Kanban IA.
