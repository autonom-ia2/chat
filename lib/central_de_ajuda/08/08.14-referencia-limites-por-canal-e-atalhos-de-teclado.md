## O que é

Duas tabelas de consulta rápida: quantos caracteres cabem numa resposta em
cada canal, e quais atalhos de teclado funcionam na tela de Conversas.

## Por que importa

Colar um texto longo, feito para e-mail, numa conversa de WhatsApp trava o
envio sem avisar o motivo. Saber o limite antes de escrever evita reescrever
tudo em cima da hora. E os atalhos tiram cliques do meio do atendimento:
resolver, trocar de aba, abrir o painel lateral. Você não precisa decorar
onde fica cada botão.

## Como consultar

**Limite de caracteres por canal**

| Canal | Limite |
|---|---|
| Nota privada (qualquer canal) | 10.000 |
| E-mail | 25.000 |
| WhatsApp (caixa nativa: Oficial Cloud API ou cadastro manual) | 4.096 |
| WhatsApp via Twilio | 1.600 |
| Telegram | 4.096 |
| TikTok | 6.000 |
| Facebook Messenger | 2.000 |
| Instagram | 1.000 |
| SMS | 320 |
| WhatsApp por QR Code (WAHA), site (chat ao vivo) e demais canais | 10.000 |

Ao passar do limite, o botão de enviar fica desabilitado. Não aparece
mensagem explicando o motivo.

**Atalhos de teclado da tela de Conversas**

Abra a lista completa em **Sua foto no rodapé da barra lateral → Atalhos do
teclado**, ou pressione **Win/⌘ + /** em qualquer tela do painel.

| Atalho | Ação |
|---|---|
| Alt + J / Alt + K | Abrir a conversa anterior ou a próxima na lista |
| Alt + E | Resolver a conversa |
| Win/⌘ + Alt + E | Resolver a conversa e ir para a próxima |
| Alt + C | Ir para o Painel de Conversação |
| Alt + V | Ir para o Painel de Contatos |
| Alt + O | Abrir ou fechar o painel lateral da conversa |
| Alt + R | Ir para a barra lateral de Relatórios |
| Alt + N | Mover para a próxima aba da lista de conversas |
| Alt + S | Ir para Configurações |
| Alt + P | Mudar para a aba **Mensagem Privada** |
| Alt + L | Mudar para Resposta |
| Alt + M | Abrir ou fechar o menu de adiar |
| Win/⌘ + Alt + A | Adicionar anexo |
| Seta para cima / para baixo | Navegar pelos itens de um menu suspenso |

## O que dá errado

- **"Colei o texto e não consigo enviar, mas não vejo erro nenhum."** Você
  passou do limite de caracteres do canal. Volte ao texto e corte pelo
  contador que aparece perto do limite.
- **"O texto que escrevi para e-mail não cabe no WhatsApp."** Os limites são
  bem diferentes: e-mail aceita 25.000 caracteres, WhatsApp aceita 4.096.
  Resuma antes de colar.
- **"Um atalho não funciona."** Alguns atalhos dependem do que está em foco
  na tela. Por exemplo, **Alt + O** só abre o painel lateral se você estiver
  dentro de uma conversa.
